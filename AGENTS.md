# Pi Agent Instructions

This folder is Pi's home. Long-term knowledge lives in the Obsidian vault `vault/`.

- `vault/Home.md` — map of everything; `vault/Mindmap.canvas` — visual mind map
- `vault/Memory/MEMORY.md`, `vault/Memory/USER.md` — durable facts and the user's profile (edit with the `memory` tool)
- `vault/Projects/<name>/<name>.md` — one note per project, with links to its sessions
- `vault/Sessions/` — one note per working session (written automatically)
- `vault/Knowledge/` — topic notes (write with the `vault` tool)
- `vault/Skills/` — skills Pi learned itself (`learn` tool); `skills/core` and `skills/library` are downloaded, read-only
- `vault/Learning Log.md` — everything Pi learned, when; `vault/Inbox/Lessons.md` — lessons waiting for a home
